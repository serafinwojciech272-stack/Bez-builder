# Bet Builder Preview

Minimal production-ready static preview for a coupon builder UI.

## Included

- Responsive desktop and mobile layout
- Sport filters
- Event and market cards
- One selected market per event
- Coupon summary
- Combined odds calculation
- Editable stake and live potential payout
- Coupon removal
- Clipboard copy
- No backend dependency

## Run

Open `index.html` in a browser or deploy the repository as a static Vercel project.

The current data is demo data. No bookmaker integration or real-money transaction flow is included.
